# Transcript Archive

Static index of transcripts produced by [Transcript-Scribe](https://github.com/Rohoe/Transcript-Scribe). Hosted via GitHub Pages from `docs/`.

The manifest lives in the Transcript-Scribe repo (`transcripts.json`). This repo is a deploy target — `docs/index.md` is regenerated by `scripts/update_index.py` over there and pushed here.

Live site: https://rohoe.github.io/transcript-archive

## How transcripts get added

1. Run the Transcript-Scribe pipeline against a YouTube URL (`ingest` → `diarize` → `cleanup` → `review` → `chapters` → `render`).
2. `uv run python scripts/publish_transcript.py <run_dir> --archive-repo ~/transcript-archive --tags ...` — creates a secret gist, updates the manifest, regenerates `docs/index.md` here.
3. `cd ~/transcript-archive && git add . && git commit && git push` — GitHub Pages rebuilds within ~30s.

## What's NOT here

- The transcript text itself — that lives in per-transcript secret gists linked from the index page.
- The pipeline source — see the Transcript-Scribe repo.
- A manifest — the canonical `transcripts.json` is in Transcript-Scribe.
